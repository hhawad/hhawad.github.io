#  Mon Site Web – CV en ligne

##  Présentation

Ce projet représente mon **CV en ligne**, conçu sous la forme d’un **site web interactif et responsive**, accessible à l’adresse suivante :
 [https://hhawad.github.io](https://hhawad.github.io)

L’objectif de ce site est de présenter mon parcours, mes compétences et mes projets de manière claire et moderne, tout en mettant en avant mes connaissances en développement web.

##  Outils et Technologies Utilisés

Pour la création de ce site, j’ai utilisé les principales technologies du web :

* **HTML5** → pour la structure du site
* **CSS3** → pour la mise en forme et le design responsive
* **JavaScript** → pour les interactions et la dynamique du contenu

L’hébergement du site est réalisé via **GitHub Pages**, ce qui permet une mise en ligne simple et rapide directement à partir du dépôt GitHub.


##  Fonctionnalités

* Design responsive (adapté aux ordinateurs, tablettes et smartphones)
* Navigation fluide et intuitive
* Présentation claire du parcours, des compétences et des projets
* Intégration de liens vers mes réseaux professionnels (ex : LinkedIn, GitHub)


##  Hébergement

Le site est hébergé sur **GitHub Pages** à l’adresse suivante :
🔗 [https://hhawad.github.io](https://hhawad.github.io)


##  Objectif du projet

Ce projet me permet de :

* Mettre en pratique mes compétences en développement web
* Créer un portfolio professionnel accessible en ligne
* Améliorer mes connaissances en **HTML, CSS, JavaScript** et **GitHub**
